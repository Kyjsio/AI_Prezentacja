# Projekt AI - prezentacje i instrukcje

Ten folder zawiera dwa proste projekty prezentacyjne utworzone w HTML/CSS/JS:

- `Prezentacja_Awatary_AI.html` – główna prezentacja o generatorach wideo i awatarach AI.
- `Instrukcje/VisionStory.html` – instrukcja krok po kroku dotycząca platformy VisionStory.

## Jak otworzyć

Najprościej uruchomić lokalny serwer w katalogu projektu i otworzyć stronę w przeglądarce:

```bash
cd "ściezka gdzie jest"
python -m http.server 8000
```

Następnie przejdź do:

- http://localhost:8000/
- http://localhost:8000/Prezentacja_Awatary_AI.html
- http://localhost:8000/Instrukcje/VisionStory.html
